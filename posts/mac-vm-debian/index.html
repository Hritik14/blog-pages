Debian on a VM on mac

Alright, I can’t stand mac’s desktop manager anymore. It’s painful. I can’t use Arch on mac since there’s no official arm variant and I never had a good day with ALARM.

Next best choice is debian. They have arm support. Get the netinst from debian website and use utm.

set up dwm

git clone https://github.com/hritik14/dwm
make debian-deps
make

set up st

git clone https://github.com/hritik14/st
make
sudo cp st /bin/st

get fonts, source code pro unzip and then

mkdir ~/.fonts
mv *.ttf ~/.fonts

!! warning REBOOT

I must've used dvorak as layout. For X to get it, gotta reboot.
